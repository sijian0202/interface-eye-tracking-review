# 界面视觉搜索与眼动实验复盘

**四件 · 2025年课程团队实验 · 2026年历史数据复算与整理**

这是一份从历史实验材料重新出发的研究记录。我参与了课程团队的眼动实验，并独立完成个人分析与报告。2026年，我借助AI与程序重新整理保留的工程和导出文件，恢复任务、核对数据结构，并修订部分历史结论。

本项目展示任务整理、数据复核、分析方法修正和研究反思，帮助回答当时究竟测试了什么，以及现存数据能够支持什么判断。

## 项目概况

| 项目 | 内容 |
| --- | --- |
| 实验范围 | 16个界面场景，涉及目标查找、信息流浏览和应用类型判断 |
| 数据规模 | 13个被试标识，208条被试与场景汇总 |
| 重点复算 | 同一组13人在4个会员区域查找场景中的表现 |
| 方法 | 目标兴趣区 AOI 恢复、描述统计、被试内置换与 Holm 多重检验校正 |
| 公开材料 | 汇总图表、方法说明、复算代码与完整复盘报告 |

## 我的工作

**2025年课程实验：**参与团队实验测试，撰写部分测试材料，基于团队共享的初始资料独立完成个人数据分析与报告，使用AI辅助分析和表达。

**2026年重新整理：**从工程恢复16个场景的任务与目标区域，核对逐人跨场景关系，统一指标口径，完成配对探索、历史结果对照及匿名公开材料。全部实验设计、设备操作与采集并非由我独立完成。

## 复算发现了什么

会员四场景来自同一组13人，需要按重复测量处理。三个相关指标经 Holm 校正后均未达到0.05，现有结果不足以认定场景间存在统计显著差异，也不能据此证明场景等效。

原报告的部分均值尚不能按现存导出口径复现。当前保留差异与处理规则，供后续核对。**现存材料尚不能核实主观侵入感评分来源，因此未纳入本次复算。**

![会员场景目标区域指标的分布汇总](./figures/member_overview.png)

M1至M4对应会员1至会员4；箱体为四分位区间，中线为中位数，菱形为均值。各场景的内容、目标面积与呈现机制存在差异，不能以注视时间长短直接判断体验优劣。

## 研究边界

这些任务主要观察视觉搜索与注意分配。找到目标后按空格，不能替代正确点击或理解核验；当前记录不能据此计算任务成功率。样本不能称为老年用户样本，也不能用于验证适老化游戏玩法。

公开内容仅含汇总与无编号分布，不含同学姓名、逐人数据、身份映射或原始截图。原始输入留在本地，因此外部读者可以审查代码和汇总，无法在缺少输入时独立复现全部计算。
